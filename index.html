Apple Private Cloud Compute (PCC) Hub

1. Hardware & PCC Core

Apasă pentru Atestare
  • Hardware-backed cryptographic identity: Keys generated during manufacturing fused into the silicon.
  • Secure and Measured Boot: Validates all code running on the device via an immutable Boot ROM.
  • Stateless computation: Personal user data is destroyed immediately after processing.

2. Sistem de operare (OS Hardening)

Apasă pentru Atestare
  • Hardened Darwin Derivative: Custom, stripped-down OS based on macOS/iOS.
  • Immutable Root Filesystem: OS files sealed in a cryptographically signed system volume.
  • Cryptographically erased data volumes: Local storage volumes wiped securely on reboot.

3. Internet & Network Security

Apasă pentru Atestare
  • Oblivious HTTP (OHTTP) Relay: User IP addresses completely masked by a third-party relay.
  • Denali Firewall Agent: Restricts communication exclusively via strict mTLS.
  • RSA Blind Signatures: Prevents the infrastructure from profiling device routing.

4. Software & Execution Safety

Apasă pentru Atestare
  • Swift on Server Memory Safety: Critical applications written in Swift to eliminate memory corruption.
  • No privileged runtime access: All remote shell debugging and developer tools are removed.

5. Software App & Workloads

Apasă pentru Atestare
  • Encapsulated Cryptexes: Workload binaries distributed as signed cryptographic extensions.
  • Sandboxed AI Execution: AI inference operations heavily sandboxed with no escalation vectors.

6. Website & Verifiable Transparency

Apasă pentru Atestare
  • Tamper-Evident Transparency Log: Software image hashes recorded publicly in append-only ledgers.
  • Virtual Research Environment (VRE): Provides open tools to boot virtual PCC nodes.
